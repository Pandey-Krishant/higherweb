# HigherWebSolution

A production-ready digital agency website built with **Next.js 16**, **TypeScript**, **Tailwind CSS**, **Three.js**, and **GSAP ScrollTrigger**.

## Tech Stack

- **Next.js 16** (App Router, `src/` directory)
- **TypeScript**
- **Tailwind CSS**
- **Three.js** — 3D hero animation (torus knot + particles + mouse parallax)
- **GSAP + ScrollTrigger** — scroll-driven animations throughout

## Pages

| Route | Description |
|-------|-------------|
| `/` | Home — 3D hero, stats counter, services grid, testimonials, CTA |
| `/about` | Agency story, animated timeline, team cards, core values |
| `/services` | Web Development, SEO, Digital Marketing deep-dives |
| `/portfolio` | Filterable project grid with hover overlays |
| `/contact` | Split layout — contact info + social links + form |

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Design System

- **Background:** Deep navy `#0A0F1E`
- **Primary accent:** Electric blue `#2563EB`
- **Headings:** Syne (Google Fonts)
- **Body:** Inter (Google Fonts)
- Glassmorphism cards, glow buttons, custom scrollbar, gradient text
